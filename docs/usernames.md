# Уникальные никнеймы

Никнейм принадлежит аккаунту и одинаков в личном пространстве и во всех организациях.
Его можно указать при регистрации или изменить в настройках профиля в вебе и мобильном
приложении. Если оставить поле при регистрации пустым, сервер назначит уникальный ник.
Вход по email сохраняется.

- Формат: 3–32 символа, латинские буквы, цифры и `_`; первый символ — буква.
- Ввод с начальным `@` допустим. Пробелы по краям удаляются, буквы приводятся к нижнему
  регистру. `@Ivan_Petrov` и `ivan_petrov` обозначают один ник.
- Уникальность действует для всех аккаунтов и защищена индексом PostgreSQL, включая
  одновременные запросы. Занятый ник возвращает HTTP 409 с понятным сообщением.
- После смены прежний ник освобождается. Ник мягко удалённого аккаунта остаётся занят.

## Поиск

В создании чата и общем поиске можно ввести ник с `@` или без него. Поиск работает по
началу ника; в личном пространстве нужно не менее трёх символов ника. Точное совпадение
показывается первым, текущий пользователь исключается, выдача ограничена 20 результатами.
`_` считается обычным символом, а не шаблоном поиска.

В личном пространстве также доступен поиск по точному полному email. В организации
сохраняется поиск по имени и email, а результаты ограничены её сотрудниками. Запрос с
`@` ищет только по нику. Найденный пользователь показывается с ником и email, чтобы
можно было различать людей с одинаковыми именами.

## Обновление существующей базы

Перед запуском нового API применить миграции:

```sh
pnpm --filter @corp/api db:migrate
```

Миграция `1764000000001-AddUsernames` назначает всем существующим пользователям ник
`user_` с полным UUID, закодированным в base36. Значения уникальны, помещаются в лимит
длины и не раскрывают email. Аккаунты, сообщения и членство в организациях сохраняются.
Пользователь может заменить назначенный ник в настройках.

Никнейм необязателен в запросе регистрации, поэтому существующие клиенты продолжают
работать. Сервер возвращает его в профиле, ответах авторизации и результатах поиска.
Изменение профиля сохраняется через `PATCH /users/me`.

Изолированный прогон `scripts/test-personal-workspaces.ps1` проверяет миграцию более
500 существующих пользователей, нормализацию, неверные значения, конфликт при
регистрации, одновременную смену на один ник, сохранение профиля и поиск в обоих
пространствах. Мобильный интерфейс дополнительно требует проверки на устройстве.
